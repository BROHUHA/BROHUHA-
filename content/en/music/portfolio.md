## Interactive Developer Portfolio & Digital Showcase

**Abin Binoy's Portfolio** is an interactive, high-performance web experience engineered to present professional software engineering projects, security research tools, and machine learning utilities with kinetic animation and minimalist aesthetics.

---

### Core Architectural Features

- **Kinetic Timeline Choreography**: Powered by **GSAP (GreenSock Animation Platform)** with multi-stage timeline sequencing, SVG mask expansions, split-text word animations, and inertial transforms.
- **Physical 3D Jewel Case & Disc Experience**: Custom CSS 3D matrix transforms simulating real physical CD cases with interactive flip mechanics, disc extraction, and high-resolution zoom.
- **Ultra-Fluid Smooth Scrolling**: Integrated with **Lenis** to provide hardware-accelerated inertia scrolling synchronized directly with GSAP ScrollTrigger timelines.
- **Tailwind CSS v4 & Modern Glassmorphism**: Utility-first CSS styling leveraging variable typography, backdrop blur filters, and dark mode aesthetics.
- **Edge Deployment & Performance Optimization**: Hosted on Vercel with automatic Brotli compression, responsive MP4 video transcoding, and sub-100ms global response times.

---

### System Architecture & Technical Specifications

- **Framework**: Built with **Vue 3** utilizing `<script setup>` Composition API for modularity and high rendering speed.
- **Styling Architecture**: **Tailwind CSS v4** with native Vite compiler integration.
- **Animation Suite**: **GSAP 3** (SplitText, ScrollTrigger, Observer).
- **Smooth Scroll**: **Lenis** 60fps inertial scrolling.
- **Global Deployment**: Continuous deployment on **Vercel** with custom edge caching.
